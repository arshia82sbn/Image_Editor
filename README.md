# Image Editor

A clean, professional Python package for image editing and drawing.

## Features
- **Image Loading/Saving**: Support for various image formats.
- **Drawing Tools**: Freehand, Rectangle, Line, and Text tools.
- **Filters**: Black & White, Blur, Emboss, Sharpen, and Smooth.
- **Undo/Redo**: Easily revert or reapply changes.
- **Customization**: Change pen color and size.

## Installation
```bash
pip install .
```

## Usage
```bash
image-editor
```
